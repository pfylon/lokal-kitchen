# 🍕 Lokal Kitchen — Боевая система доставки еды (Production Edition)

Профессиональный, конверсионный мини-сайт и интерактивный каталог для ресторанов, кафе, пиццерий и суши-баров с прямым оформлением заказов в **Telegram** и **WhatsApp** без комиссий агрегаторов (экономия 30–35% с каждого чека).

- **🌐 Live Demo (GitHub Pages):** [https://pfylon.github.io/lokal-kitchen/](https://pfylon.github.io/lokal-kitchen/)
- **📦 Репозиторий:** [https://github.com/pfylon/lokal-kitchen](https://github.com/pfylon/lokal-kitchen)

---

## 🌟 Что реализовано в коде (Архитектура и фичи)

1. **Архитектура Single Source of Truth (`PRODUCTS` в JS)**:
   - Все данные блюд (названия, фото, описания, цены, граммовки, бейджи, теги аллергенов/диеты, размеры и модификаторы) вынесены в чистый массив объектов `PRODUCTS` в `script.js`.
   - Каталог рендерится динамически — разметка безопасна и не зависит от жестко зашитого HTML.

2. **Модификаторы блюд (Кастомизация в модальном окне)**:
   - При клике на карточку или кнопку «Настроить» открывается стильный тёмный диалог.
   - Выбор размера/порции (например, *30 см* vs *40 см* с автоматическим пересчетом дельты цены).
   - Выбор платных и бесплатных допов (двойной сыр, чесночный бортик, соусы, выбор молока).
   - Живой пересчет итоговой цены прямо в модалке перед отправкой в корзину.

3. **Выбор способа оплаты**:
   - В корзине добавлены интерактивные радиокнопки:
     - 💳 **Картой курьеру** (при получении терминалом)
     - 📲 **СБП (QR-код / онлайн перевод)**
     - 💵 **Наличными** (при выборе появляется поле «Сдача с какой суммы?»)
   - Способ оплаты автоматически включается в формируемый чек для мессенджера.

4. **Автозаполнение данных клиента (CRM в браузере)**:
   - При первом заказе имя, телефон и адрес сохраняются в `localStorage`.
   - При повторных визитах данные подставляются автоматически, а гость видит приятное приветствие: *«✨ С возвращением! Данные подставлены автоматически»*.
   - Повторный заказ оформляется буквально за **2 клика**.

5. **Безопасный расчет и надежное хранение**:
   - Все расчеты сумм, скидок самовывоза (-10%) и бесплатной доставки производятся внутри JS.
   - Корзина и профиль сохраняются при обновлении страницы.
   - Аккуратная авторская строка по центру футера: `Разработка и дизайн под ключ: @zifca`.

## 🚀 Как запустить и протестировать локально

1. Откройте папку `coffe_mein` на компьютере.
2. Дважды кликните по файлу `index.html` или перетащите его в окно браузера (Chrome, Safari, Edge, Яндекс Браузер).
3. Нажмите `F12` и включите режим эмуляции смартфона (`Ctrl + Shift + M`), чтобы проверить:
   - Клик по карточке пиццы — откроется модалка с выбором 30/40 см и допов;
   - Выберите размер 40 см (+320 ₽) и чесночный бортик (+110 ₽) — цена пересчитается с 690 ₽ до 1 120 ₽;
   - Нажмите «Добавить в заказ» — товар упадет в корзину с точным описанием модификаторов;
   - Откройте корзину через плавающую нижнюю кнопку;
   - Введите имя, телефон и адрес, выберите способ оплаты «Наличными» (появится поле сдачи);
   - Нажмите «Заказать в Telegram» или «Заказать в WhatsApp» — заказ сформируется в готовое сообщение;
   - Перезагрузите страницу — корзина и данные клиента останутся на месте, появится бейдж автозаполнения.

## ⚙️ Настройка под реального клиента (за 1 минуту)

Когда вы продаете этот сайт ресторану или кафе, откройте файл [script.js](file:///e:/coffe_mein/script.js) и отредактируйте объект `CONFIG` в самом верху (строки 10–18):

```javascript
const CONFIG = {
  restaurantName: 'Lokal Kitchen',         // Название заведения клиента
  telegramUsername: 'zifca',                // Telegram-аккаунт или бот менеджера (без @)
  whatsappPhone: '79991234567',            // Номер WhatsApp для приема заказов (без +)
  freeDeliveryThreshold: 1200,             // Порог бесплатной доставки в рублях
  deliveryPrice: 150,                      // Стоимость доставки, если сумма меньше порога
  pickupDiscountPercent: 10,               // Процент скидки при самовывозе
  pickupAddress: 'г. Москва, ул. Большая Покровская, 14 (вход с аллеи)' // Адрес кухни
};
```

Для редактирования блюд, цен и добавления новых позиций просто меняйте массив `PRODUCTS` в [script.js](file:///e:/coffe_mein/script.js) — интерфейс перестроится автоматически!
